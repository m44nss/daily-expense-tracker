# Daily Expense Tracker

A beginner-friendly expense tracker made with vanilla HTML, CSS and JavaScript.

## Features
- Add expenses with a name, amount and category
- View total spending and largest expense
- Filter by category
- Delete one expense or clear all expenses
- Save data in browser `localStorage`
- Responsive mobile and desktop layout

## Run locally
Open `index.html` in your browser. No dependencies or build step are needed.

## Concepts practised
DOM manipulation, event listeners, form validation, array methods, localStorage, accessible labels and responsive CSS.
